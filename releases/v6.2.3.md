# v6.2.3 - 里程、文档和双宿主功能终于在同一版本里

## 发版范围

本次发布覆盖从 `v6.2.1` 到 `v6.2.3` 的全部变化，包括上游 6.2.2 修复、Codex 适配和只读 Dashboard 升级。

## 给作者看的变化

- Claude Code 与 Codex 现在共用同一套写作 Skill、数据链和 `master` 主线；从仓库默认分支安装即可同时获得两边已完成的功能。
- Dashboard 文档浏览会渲染 Markdown，而不是显示原始标记；JSON 会自动缩进，每个字段单独成行。
- 新增「里程一览」标签页，可按“卷 → 阶段 → 章节”逐层展开。详细卷纲里的全部章节都会列出，即使正文还没开始写，也能看到计划中的位置。
- 章节状态会区分已完成、进行中和计划中；人物、物品、能力等故事要素也能在同一页快速查看推进情况。
- 纳入上游开放环聚合、文风记忆消费修复和 WorkBuddy 集成，减少长篇写作中的状态遗漏。

## 是否需要改旧项目

不需要。已有书项目不需要迁移 `.story-system/` 或 `.webnovel/` 数据。

Dashboard 会按现有详细卷纲、索引、状态和数据库生成只读视图；如果旧项目缺少某类派生数据，对应区域会降级为空状态，不会改写故事事实源。

## 适合谁升级

- 同时使用 Claude Code 和 Codex 写作的人。
- 希望通过 Dashboard 快速检查分卷、阶段、章节和故事要素进展的人。
- 需要浏览较长 Markdown 设定或 JSON 状态文件的人。

## 已知影响

- 「里程一览」能展示多少计划章节，取决于书项目的详细卷纲是否包含可识别的章节标题和阶段结构。
- Dashboard 仍是只读派生视图，不会替代 `.story-system/` 与 accepted `CHAPTER_COMMIT` 事实源。

## 给维护者

- Codex 通过 `.codex-plugin/plugin.json`、`.agents/plugins/marketplace.json` 和共用 `skills/` 接入；Claude 专属 Hook 不直接注册到 Codex。
- 新增 `/api/milestones` 聚合接口、详细卷纲解析、里程碑前端页面、Markdown/JSON 文档预览及相应单元测试。
- `sync_plugin_version.py` 与插件包校验同时覆盖 Claude 和 Codex 清单，避免双宿主版本号再次漂移。
- 此版本以远端 `master` 为唯一发布主线；原 `main` 历史保留作为迁移前备份，不做无关历史合并。
